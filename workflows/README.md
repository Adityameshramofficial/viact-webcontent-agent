# Workflows

Markdown SOPs (Standard Operating Procedures) that define objectives, required inputs, which tools to use, expected outputs, and edge case handling.

## Workflow Template

Each workflow file should include:

- **Objective** — what this workflow accomplishes
- **Inputs** — what data or parameters are required
- **Steps** — ordered list of tool calls and decisions
- **Outputs** — what the workflow produces and where it goes
- **Edge Cases** — known failure modes and how to handle them
- **Notes** — rate limits, quirks, lessons learned
